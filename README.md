# API Response Compare

Compare responses of two APIs directly inside Visual Studio Code.

## Features
- Compare two APIs (GET / POST)
- Supports JSON request body
- Clear readable difference output
- Helpful for backend testing & debugging

## How to Use
1. Press `Ctrl + Shift + P`
2. Select **Compare Two APIs**
3. Enter both API URLs
4. Choose method (GET or POST)
5. See differences instantly

## Example
- API 1: `/v1/report`
- API 2: `/v2/report`

## Output
Shows:
- Changed fields
- Old value vs new value
